# ADR 0011 — Concept 상세 설명 기준과 Transformer 전체 파일럿 집필

상태: **인간의 명시적 결정 반영**

결정일: 2026-10-13 (Asia/Seoul)

## 승인 근거와 결정

이번 TRANSFORMER Full Pilot Chapter v0.1 요청에서 인간 저자는 “모든 Concept는 v0.3의 상세 설명 수준 이상으로 교육적으로 충분히 설명되어야 한다”고 결정했다. K0302·K0303의 필요성·메커니즘·도출·단계별 계산·전체 모델 연결을 최소 기준으로 삼고, 복잡한 Concept에는 더 깊은 설명을 요구한다. [집필 정책](../TEXTBOOK_AUTHORING_POLICY.md#모든-concept의-최소-교육적-설명-수준)에 최소 delta로 반영했다.

설명 종류와 깊이는 Concept의 성격에 맞추며 균등 분량이나 `1 K = 1 Section`을 도입하지 않는다. 원리 이해와 관련 LO의 실제 연습 가능성을 기준으로 검토하고 언급·번호 coverage로 대체하지 않는다.

인간 저자는 Transformer v0.3 문체와 설명 흐름을 다소 부족하지만 전체 Chapter 집필을 진행할 수 있는 수준으로 조건부 수용했다. 승인 범위는 상세 설명 기준과 K0302–K0312·LO0559–LO0572 전체 파일럿 집필 진행이다. v0.3 모든 문장의 완벽성, 전권 최종 문체, 이번 파일럿 최종 승인이나 학습효과 실증을 포함하지 않는다.

## 경계와 이력

0011 번호 미사용을 확인했다. ADR 0010과 이전 후보의 bytes·역사적 승인 사실은 보존한다. Concept/LO identity·home·출판 번호·선수관계 admission은 변경하지 않는다. 시작 main·local HEAD·origin/main·actual remote main은 모두 `46502b34957edc445817efe95804a0847197febc`, 작업 트리는 clean이었다. 새 후보는 chapter-transformer-pilot-v0.1이다. 최종 인간 편집 검토는 별도다.
