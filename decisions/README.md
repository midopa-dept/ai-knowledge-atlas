# Decisions

중요한 architecture, editorial, ontology 결정을 ADR(Architecture Decision Record) 형태로 기록한다.

권장 항목:

- **Context:** 결정이 필요한 배경
- **Decision:** 선택한 결정
- **Rationale:** 선택의 근거
- **Consequences:** 결정에 따른 영향과 trade-off
