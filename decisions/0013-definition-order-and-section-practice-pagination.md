# ADR 0013 — 정의 서술 순서와 절 종료 연습의 페이지 구분

상태: **인간의 명시적 공통 편집 결정 정본화 — 첫 절 국소 마감 후보 검토 대기**

결정일: 2026-10-13 (Asia/Seoul)

## 배경과 결정

인간 저자는 Transformer 첫 상세 절의 설명 깊이와 연습 구성에 전반적으로 만족하며 기존 성과를 유지한 국소 편집을 요청했다. 공통 집필 규칙으로 직접 승인한 것은 다음 두 가지다.

1. 수학적 정의를 대상의 선언 → 정확한 수식·조건 → 기호·정의역·첨자의 의미 → 추가 설명과 해석의 순서로 서술한다. 필요한 정의역·조건은 짧게 먼저 밝힐 수 있고 획일적 문장 틀이나 설명 축소를 강제하지 않는다.
2. 절 종료 연습은 제목부터 새 페이지에서 시작하며 제목·안내·첫 문제를 같은 시작 지면에 연결한다. 홀수 페이지 강제·불필요한 빈 페이지는 만들지 않는다. 유제·짧은 이해 확인의 본문 위치는 유지한다.

두 규칙을 [교재 집필 정책](../TEXTBOOK_AUTHORING_POLICY.md)에 최소 반영한다. 미사용 번호0013을 확인했으며 ADR0008–0012를 소급 수정하지 않는다.

## 근거와 영향 범위

사용자가 전달한 GPT 상위 오케스트레이터의 독립 검토 지적은 현재 후보의 개선 근거다. 정리 명료화·이해 확인 해설 분리·제작 상태 문구 제거·볼록 영역 그림·핵심 연산 안내·문제 묶음·실행 경로는 이 후보에서 적용하며, 이를 새 전권 정책의 인간 승인으로 확대하지 않는다.

기존 첫 상세 절 후보를 국소 개정한다. K0302·LO0559의 의미·26문항 및 해설·학습 소스·Ontology v1.0·출판 계층·공식 Registry를 보호한다. 임시 장10과 정본 출판 번호는 구별하고 새 공식 ID를 발급하지 않는다.

시작 main·local HEAD·origin/main·실제 remote main은 `865c90ff946cf918b049b27b8437ca906ed677af`, 작업 트리는 clean이었다. 두 검토 PDF와 영향받는 검증을 갱신하며 10.2절·전체 Chapter 집필을 시작하지 않는다. 인간의 긍정 평가·AI 검증을 최종 교육 승인이나 실제 학습효과 실증으로 표시하지 않는다.
