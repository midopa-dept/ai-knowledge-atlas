# ADR 0014 — 외부 지식 권위와 자기참조 금지

상태: **인간 저자의 직접 승인 정본화 — 전60 Chapter 적용**

결정일: 2026-10-15 (Asia/Seoul)

## 배경과 승인

인간 저자는 이번 요청 「AI Knowledge Book — External Knowledge Authority & Anti-Self-Reference Policy」에서 기술적·학술적 교육 내용은 독립 검증 가능한 외부 지식에 근거해야 하며 저자의 서적·프로젝트·Harness·Ontology·Registry·AI 생성 문서를 기술적 진실의 근거로 삼지 말 것을 최상위 집필 결정으로 직접 승인했다. 이는 AI의 제안이나 검토 판정으로 추론한 승인이 아니다. HARNESS 한 Chapter가 아니라 전체60 Chapter에 적용하고 충돌하는 기존 집필 방향·후보는 검토·교정 대상으로 삼는다.

## 결정

[교재 집필 정책](../TEXTBOOK_AUTHORING_POLICY.md)의 기존 출처·근거, 독자 참고문헌, 집필·독립 검토에 최소 통합한다. 교육 범위·수행 목표·문서 관리의 권위와 학술적 사실의 권위를 분리한다. 논문·전문 서적·공식 기술 문서·실제 엔지니어링 사례의 원문을 조사하며 단일 회사 사례는 보편 표준을 입증하지 않는다. 다른 AI의 설명·재귀 요약·생성 검토는 독립 문헌이 아니다.

Concept/LO 확인 뒤 외부 원문을 먼저 조사하고 주장별 저자·발표 시점·버전·위치·확인 근거·주장 한계를 내부 장부에 연결한 후 질문 중심 본문을 쓴다. 근거가 없으면 삭제·한정·미해결 보고한다. 정본 범위와 실질 충돌은 별도 의미 검토로 넘기며 조용한 의미 변경·허위 인용으로 해결하지 않는다. 저자 설계를 먼저 원리로 만들고 외부 문헌을 사후 맞추지 않는다.

교육용 모델은 허용하되 외부 원리·단순화한 예시·특정 실행의 결과·저자 설계·미합의 해석을 구별한다. 여섯 사건·가상 예약 시스템은 공인 표준이 아니다. 내부 문서/Registry/Learning Source는 독자용 기술 참고문헌·미주에서 제외하고 필요한 제작·실습 추적을 별도 산출물로 보존한다. 코드 경로·revision·명령은 실습 재현 자료이고 다른 Chapter 안내는 학습 경로다.

작성과 분리된 검토자가 주요 주장과 외부 원문을 대조한다. 근거 없는 사실·미확인/부재 인용·잘못 귀속·자기참조·단일 구현 일반화는 차단 결함이다. 기술 검토는 인간 편집·실제 학습효과·출판 승인을 대신하지 않는다.

## 산출물 경계와 결과
