# References

학술 출처와 claim provenance를 관리한다. 사실적·연구적 주장에는 가능한 한 claim 단위로 근거 출처를 연결하며, 서지정보는 `bibliography.bib`에 관리한다. 확인하지 않은 출처나 샘플 citation을 임의로 넣지 않는다.

출처 유형은 primary paper, textbook, survey, systematic review/meta-analysis, official documentation/engineering report, benchmark, preprint 등을 구분한다.

출처 유형과 주장의 근거 수준은 구분해서 기록한다. 확립된 이론, 확립된 연구, frontier research, interpretive framework, practical heuristic을 명확히 구분하고, 출처가 실제로 뒷받침하는 주장의 범위를 추적한다.
